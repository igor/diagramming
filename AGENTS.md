# Diagram authoring

Experimental release candidate: a portable agent skill and deterministic SVG export toolkit. The repository root is the installable skill folder. Keep its instructions usable across harnesses; product-specific invocation belongs in the README.

Preserve user intent, sources and uncertainty. A passing render does not prove that a diagram explains its subject. Publication, installation into a user's live skill directories and destructive operations require explicit authorization.

Use apply_patch for source edits. Preserve unrelated work. No private examples, local source paths, credentials, conversation excerpts or branded design-system bindings in committed files. Generated manifests can include provenance; inspect them before publishing.

Keep dependencies and abstractions small. Run the documented tests and clean-install quickstart before declaring a release ready. Inspect stills and decoded video frames. Distinguish actual operating-system/harness tests from documented compatibility.
